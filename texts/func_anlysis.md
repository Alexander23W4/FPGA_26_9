# 灰度归一化:

原始图像的像素值范围可能不同。
例如：

图像 A：0 ~ 255
图像 B：100 ~ 2000
图像 C：-1000 ~ 3000

归一化就是把它们转换到统一范围 比如:  0 ~ 1 或 0 ~ 255




# 伪彩色映射:

原图可能是：
黑 → 灰 → 白
伪彩色把不同灰度映射成颜色。

例如：
低灰度 → 蓝色
中灰度 → 绿色
高灰度 → 黄色
最高 → 红色

类似：
0       蓝
↓
128     绿
↓
255     红

人眼对颜色差异通常比对灰度差异更敏感，所以更容易发现细微变化。


# 直方图均衡:

图像可能整体灰度集中：████████████

直方图均衡会尽量把灰度拉开：█ █ █ █ █ █ █

提高整体对比度，让细节更明显。

██████

# 轮廓绘制

Mask 是：
████
████
████

轮廓只提取边界：
┌────┐
│    │
└────┘

然后画到原图上。

例如：原图 + 绿色轮廓

目的：清楚显示目标边界，同时不会遮挡内部图像。

# 面积估计

如果已经得到一个目标区域：

可以计算：目标像素数量

例如：
10000 pixels
如果知道图像空间分辨率：
1 pixel = 0.5 mm × 0.5 mm
那么：面积=10000 × 0.5 × 0.5


# 体积估计

通常用于：CT MRI

有很多张切片：
Slice 1
Slice 2
Slice 3
...

每张图计算面积：
A1
A2
A3

然后：体积 ≈ 面积 × 切片厚度

简单情况：V ≈ Σ(Ai × thickness)

例如：
第 1 层：10 cm²
第 2 层：12 cm²
第 3 层：11 cm²

切片厚度：0.5 cm

那么：V ≈ (10 + 12 + 11) × 0.5
