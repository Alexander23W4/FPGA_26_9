# 选题指南

## 一、总体说明

本指南设置以下两个选题方向：

1. **基于 FPGA 的医学影像实时分析与智能辅助展示系统设计**
2. **面向自动驾驶小车的智能感知与先进显示系统设计**

参赛队伍可根据技术基础、硬件条件和应用兴趣选择其中一个方向完成作品。

参赛作品应围绕真实或合理仿真的应用场景，构建从数据输入、缓存调度、实时处理、智能分析到结果叠加和显示输出的完整系统。

FPGA 应承担图像处理、智能推理、几何变换、传感器融合、后处理或显示叠加中的关键任务，不得仅作为视频直通、接口转换或简单数据搬运设备使用。

允许采用片上处理器、上位机或辅助单片机完成以下工作：

- 系统控制
- 参数配置
- 模型训练
- 文件管理
- 低速传感器采集
- 执行机构驱动

但作品的核心数据通路和主要计算任务应在 FPGA 可编程逻辑中实现。

参赛队伍应在设计报告中明确软硬件分工，并说明以下内容：

- FPGA 模块的功能
- 数据流
- 缓存结构
- 时钟域
- 定点化策略
- 存储访问方式
- 资源占用
- 性能指标

## 二、选题方向

### 1. 基于 FPGA 的医学影像实时分析与智能辅助展示系统设计

本题面向 CT、MRI、超声、内镜、眼底、显微等医学影像应用场景，要求参赛队伍基于 FPGA 设计一套实时或准实时的医学影像分析与智能辅助展示系统。

作品应形成以下完整链路：

> 影像输入 → 预处理 → 智能分析 → 结果叠加 → 显示输出

FPGA 应承担以下任务中的一项或多项关键工作：

- 核心图像处理
- 模型推理
- 几何变换
- 缓存调度
- 分割后处理
- 图形叠加

应避免仅在软件端完成全部功能。

### 2. 面向自动驾驶小车的智能感知与先进显示系统设计

本题面向智能车场景，要求参赛队围绕“智能感知 + 先进显示”一体化设计一套可在车模平台上运行、可交互、可量化的完整工程作品。

作品应实现以下完整数据流：

> 传感器/数据输入 → 实时处理 → 感知结果生成 → 显示输出

核心感知与计算任务应在 FPGA 平台上完成。

题目设置以下三个选做方向，参赛队须至少选择其中一个方向完成，鼓励跨方向融合：

- 单目/双目深度估计
- 多目全景拼接
- 多传感器采集在环与 AR/VR

### 3. 自主命题

本次竞赛开设自主命题赛道。各参赛队可基于 FPGA 技术，自主设计并实现一个具有创新性和实用性的项目。

参赛团队需围绕以下领域自主命题，完成系统功能设计、硬件开发、程序编写及调试：

- 信号处理
- 数据通信
- 人工智能加速

#### 核心任务

- 确保系统稳定运行，满足实时性和可靠性要求
- 突出创新点，体现一定的应用价值
- 明确量化技术指标，例如处理速度、精度等

评分将综合考量以下方面：

- 创新性
- 功能完整性
- 技术难度
- 文档规范
