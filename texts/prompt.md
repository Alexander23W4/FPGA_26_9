# 附录A：题目一相关要求及推荐开源数据

## 一、基础要求

1. **完成医学影像数据处理链路**

    完成至少一种医学影像模态的数据输入、缓存、处理和输出显示。

    - 输入可来自上位机、SD卡、DDR、以太网、USB、摄像头或片上处理器。   // usb  摄像头  片上处理器
    - 输出可采用HDMI、VGA、LCD或上位机界面。

2. **实现至少三类基础处理或显示功能**

    可选功能包括：

    - 灰度归一化；    //
    - 窗宽窗位调节；
    - 伪彩色映射；
    - 直方图均衡和CLAHE；
    - 去噪滤波和边缘增强；
    - 阈值分割；   //
    - 形态学开闭运算；
    - 连通域统计；
    - 分割掩膜叠加；
    - 轮廓绘制；  //
    - 面积或体积估计。

3. **实现至少一种具有明确医学应用意义的智能分析功能**

    例如：

    - 器官或组织分割；   //
    - 病灶候选区域检测；  //
    - 细胞计数；
    - 血管或视盘区域提取；
    - 超声目标区域跟踪；
    - CT/MRI图像配准；
    - 三维切片浏览。

4. **由FPGA完成核心算法或核心加速模块**

    需要说明以下内容：

    - 模块划分；
    - 数据流路径；
    - 缓存机制；
    - 时钟域设计；
    - 定点化策略；
    - 片上及片外存储访问方式；
    - 关键资源占用。

5. **具备稳定、连续、可交互的展示能力**

    显示端或上位机界面应能够标注：

    - 当前处理模式；
    - 阈值参数；
    - 分割结果；
    - 推理耗时；
    - 帧率；
    - 资源统计等信息。

6. **规范使用医学数据**

    所有医学数据应来自公开数据集、公开挑战赛数据、仿真数据或匿名教学数据。作品必须声明：

    > 仅用于工程教学与算法演示，不作为临床诊断依据。

## 二、拓展要求

1. 实现轻量化U-Net、MobileU-Net、UNet++、ResUNet、nnU-Net风格小模型或自定义医学分割网络，并完成INT8/INT4量化、剪枝或知识蒸馏后在FPGA上进行推理加速。
2. 支持2.5D或3D医学体数据处理，例如相邻多切片输入、patch-based体数据分割、MPR多平面重建、最大密度投影（MIP）或分割体积统计。
3. 支持交互式医学分割展示，例如通过鼠标、按键、触摸屏或上位机选择ROI、点提示、框提示或阈值参数，并由FPGA实时更新分割掩膜、轮廓和定量结果。
4. 实现图像配准或多模态融合，例如CT-MRI刚性配准、超声连续帧配准、术前影像与实时图像对齐，体现几何变换、插值和代价函数计算的硬件化设计。
5. 实现“原图+增强图+分割掩膜+量化指标”的同屏展示，例如左右分屏、四宫格、透明Alpha叠加、轮廓叠加、伪彩色热力图、实时FPS和延迟显示。
6. 给出与CPU或软件基线的对比，包括处理帧率、单帧或单切片延迟、吞吐率、功耗估计、LUT/FF/BRAM/DSP占用、DDR带宽估计以及算法精度变化。

## 三、推荐开源数据集

为满足公开、合规和可复现实验的要求，推荐优先考虑STARE、ISIC Challenge 2016 Task 1和CAMUS三类公开数据集。三者分别对应眼底、皮肤镜和心脏超声三种典型医学影像模态，可支撑基础图像处理、轻量分割模型部署、分割结果叠加和定量测量展示。

使用其他数据集时，应在设计报告中说明数据来源、许可和使用范围。

### 1. STARE：视网膜眼底血管分割

**下载内容：**

- 官网或血管分割页面；
- 原始20张眼底图像tar；
- Adam Hoover人工血管标注；
- Valentina Kouznetsova人工血管标注。

**数据内容：**

STARE血管分割页面提供20张实验用视网膜眼底图像，并提供两套人工血管网络标注，可用于血管分割、血管轮廓叠加和分割指标评估。

**简单分析：**

该数据集规模小、图像为2D、标注明确，适合作为题目A的基础演示主线。FPGA端可实现绿通道提取、灰度归一化、CLAHE或滤波、阈值或轻量U-Net血管分割、形态学开闭运算、连通域统计、血管掩膜Alpha叠加以及Dice/IoU统计。

其局限是样本数量较少，不宜作为泛化性能的充分证明，应定位为工程教学演示和算法链路验证。

### 2. ISIC Challenge 2016 Task 1：皮肤镜皮损分割

**下载内容：**

- 挑战赛数据总页；
- 2016 Task 1训练图像ZIP；
- 2016 Task 1训练掩膜ZIP；
- 2016 Task 1测试图像ZIP；
- 2016 Task 1测试掩膜ZIP。

建议使用 `2016 Task 1 Lesion Segmentation` 数据。

**数据内容：**

ISIC 2016 Task 1提供900张训练皮肤镜JPEG图像、900张PNG二值分割掩膜、379张测试图像和测试掩膜，许可标注为CC-0。

**简单分析：**

该数据集适合展示“原图+增强图+分割掩膜+量化指标”的完整链路，医学应用意义明确。可训练MobileU-Net或小型U-Net，并将INT8/INT4量化模型或分割后处理部署到FPGA。

由于皮肤镜图像存在颜色、光照、毛发遮挡和尺度差异，建议离线统一缩放到256×256或512×512，在线完成RGB转灰度或HSV、颜色归一化、二值掩膜叠加、轮廓绘制和皮损面积估计。

### 3. CAMUS：心脏超声多结构分割

**下载内容：**

- CAMUS官方数据说明页；
- HumanHeartProject下载入口；
- 训练集说明页。

**数据内容：**

CAMUS是2D心脏超声多结构分割数据集，整体包含500名患者检查，其中训练集450例带专家人工参考，测试集50例。原始输入图像采用raw/mhd文件格式。

**简单分析：**

CAMUS更适合作为题目A的拓展演示，用于超声图像增强、左心室/心肌/左心房区域分割、轮廓叠加、面积或体积估计以及ED/ES帧对比。

工程上建议先离线将raw/mhd转换为8bit或16bit灰度PNG/RAW序列，再输入FPGA。基础演示可做单帧分割，拓展可做2.5D相邻帧或序列输入和定量指标显示。

该数据集真实临床异质性强，低对比度和图像质量较差的样例较多，应在演示中保留失败案例说明。
