# 连续帧整数平移配准

当前工程使用本目录的 `registration_top`，与 `medical_metrics_full/rtl` 中原始演示版本分开编译，避免同名模块重复定义。

## 接口和输出

输入：`in_data / in_valid / in_ready / in_eof`；输出：`out_data / out_valid / out_ready / out_eof`。
每个握手传递一个 8-bit 灰度像素，`eof` 对应整帧最后一个像素。默认每帧 256×256。
输出反压时，valid、data、eof 保持不变。正常情况下每输入一帧，输出一帧；首帧原样输出并建立参考。

搜索比较相邻两张原始帧的中心 48×48 ROI，候选整数位移范围为 ±8 像素：

```text
reference(x,y) ≈ current(x+dx,y+dy)
```

默认 `ACCUMULATE=1`，相邻位移累加后，将输出对齐到首帧坐标；`ACCUMULATE=0` 仅应用本次相邻帧位移。
按偏移重读当前帧，越界像素补零，输出尺寸始终不变。复位清除参考及累计位移，不清空 BRAM。
切换到另一个患者或序列时，应重新建立参考；当前顶层退出医学分支会复位本模块。

`reg_dx/dy` 是本次相邻帧位移，`reg_sad` 是最佳候选的完整 SAD。`reg_valid` 在首次搜索完成后保持高；
`reg_done` 每次搜索完成脉冲一拍，早于该帧输出结束。`frame_count` 统计完整合法输入帧。
`frame_error` 是复位清零的粘滞错误位；短帧丢弃，超长帧排空到 EOF，均不替换前一张合法参考。

## 性能设计

- 同步 RAM 读、像素绝对差、累加分级流水，每拍比较一对像素。
- 地址递增和行跨步替代逐像素坐标乘法。
- 先比较零位移；零位移 SAD 为零时，直接得到可证明的最优解。
- 候选的部分 SAD 大于当前最优完整 SAD 时提前结束。差分非负，淘汰不会改变最优解。
- 同 SAD 优先较小的曼哈顿位移，纯色帧不会固定偏向左上角。
- 两块原始帧 RAM 交换角色，取消逐帧复制。共需 128 KiB 帧缓存。
- 当前帧输出与下一帧接收重叠；两者结束后开始下一次搜索。
- 输出使用四像素 FIFO，并为同步 RAM 在途读取预留空间。

XSim 默认参数下，强制全部 289 个候选都完成的测试结果：

| 测量 | 周期数 | 按 80 MHz 换算 |
|---|---:|---:|
| 搜索 | 667,013 | 8.337663 ms |
| 连续帧搜索完成间隔，含接收/输出重叠 | 732,553 | 9.156913 ms，约 109 FPS |

这是无外部停顿的模块级仿真结果，不代表整机网络、GUI 或布局布线后的实测性能。
算法只处理整数平移，未实现旋转、缩放、局部形变或临床运动跟踪。

## 顶层接线

`rtl/frame_xbar.v` 在 `top1` 中接收 `axi2px` 输出，根据 `top_threshold_demo.reg_mode_out` 分流。

```text
reg_mode=0: axi2px → frame_xbar → denoise → threshold → 原有显示/回传
reg_mode=1: axi2px → frame_xbar → registration_top → 输出预留
```

分支从首个有效像素开始锁定，直到 EOF 握手结束，即使首像素被反压或帧中修改 MODE，也不会拆帧。
当前配准输出按要求留空，`out_ready=1`，医学分支不会产生 HDMI/TCP 结果。
GUI 模式切换经 PS 已有 `M` 命令写 MODE 寄存器（WORD 0x00 / 字节偏移 0x00），校验回读后更新页面状态。
当前 GUI 会拒绝在医学模式启动必须等待图像回传的任务，避免等待尚未接通的输出。

## 本地验证

在仓库根目录运行：

```bash
python rtl/inter_fr/tests/run_checks.py
```

覆盖同步 RAM 读时序、完整 SAD、提前淘汰、随机帧与穷举黄金结果比较、默认尺寸性能、
逐像素校正结果、连续收发、输出反压、帧长异常、复位恢复和帧级路由切换。
可使用 `--top tb_registration_stream` 仅运行指定测试，`--out` 指定临时输出目录。
