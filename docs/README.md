---

## 三类的区别

| 目录 | 谁写的 | 会不会变 | 作用 |
|---|---|---|---|
| `design/` | 你们 | 项目推进中会改 | **要做什么** |
| `reference/` | 第三方 | 不会变 | **外部依据** |
| `env/` | 我们的核对结果 | 确认后基本不变 | **板子/工具是什么样** |

## 权威来源优先级（配置任何东西之前先看这个）

| 级别 | 来源 |
|---|---|
| ★★★ | **实物丝印版本** |
| ★★★ | `光盘资料\09_硬件图纸\ACZ7015-CORE-原理图250804.pdf`（核心板） |
| ★★★ | `光盘资料\09_硬件图纸\ACZ7015-CB-RevA底板原理图.pdf`（底板） |
| ★★ | `光盘资料\09_硬件图纸\ACZ7015-CB-RevA-SCH\*.SchDoc`（Altium 源工程） |
| ✗ | `光盘资料\08_器件手册\` 芯片清单 —— **跨版本混装，不可作依据** |
| △ | `光盘资料\04_引脚信息\` xlsx —— 需与图纸交叉核对 |

> 例：器件手册里有 `N25Q128A / USB2514B / FT232HL`，
> 但图纸（RevA / 250804）实际用的是 `W25Q128JVSIQ / CH334H+SL2.1S / M02HS2`。
