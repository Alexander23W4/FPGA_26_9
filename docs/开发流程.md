# 阶段 1 · ARM 侧（先做这个，最快见效）

**目标**：串口打印出你自己写的 hello。

```
ps7_preset.tcl  →  Vivado  →  .xsa  →  Vitis  →  BSP  →  你的 C  →  串口
```

## 1.1 生成硬件平台

**你敲：**

**它在干什么**：建工程 → 建 BD → 放 PS7 并**套用 `ps7_preset.tcl`** → 出位流 → 导出 `.xsa`

## 1.2 在 Vitis 里建 Platform

**你点：**

### 要写什么（规格，自己实现）

**版本 A —— 用 BSP，最省事**
- 包含 `xparameters.h` 和 `xil_printf.h`
- 主函数里 `xil_printf` 打印一行字
- 死循环

**版本 B —— 直接戳寄存器（推荐先写这个，对应你 ysyx 的 AM）**

需要的硬件事实：

| 项 | 值 | 从哪来 |
|---|---|---|
| UART1 基地址 | `0xE0001000` | `xparameters.h` 的 `XPAR_XUARTPS_0_BASEADDR` |
| 参考时钟 | 100 MHz | `ps7_preset.tcl` 的 `UART_PERIPHERAL_FREQMHZ` |
| 波特率 | 115200 8N1 | 你要的 |

寄存器偏移（这几个从 Vitis 安装目录的 `xuartps_v3_13/src/xuartps_hw.h` 里查）：

| 寄存器 | 偏移 |
|---|---|
| CR（控制） | `0x00` |
| MR（模式） | `0x04` |
| BAUDGEN（波特率发生器） | `0x18` |
| BAUDDIV（分频） | `0x34` |
| SR（状态） | `0x2C` |
| FIFO（收发） | `0x30` |

要用到的位：

| 位 | 值 | 含义 |
|---|---|---|
| `CR_RXRST` | `0x01` | 复位接收 |
| `CR_TXRST` | `0x02` | 复位发送 |
| `CR_RX_EN` | `0x04` | 使能接收 |
| `CR_TX_EN` | `0x10` | 使能发送 |
| `MR_PARITY_NONE` | `0x20` | 8 数据位 + 无校验（8N1 里 1 停止位本身就是 0） |
| `SR_TXFULL` | `0x10` | TX FIFO 满 |

**波特率公式**：`波特率 = 参考时钟 / (BAUDGEN × (BAUDDIV + 1))`

自己算一组能凑出 115200 的 `BAUDGEN` / `BAUDDIV`（提示：试着让 `BAUDDIV = 6`）。

**`putch` 的逻辑**（这就是你的 AM）：
1. 读 SR，如果 `TXFULL` 置位就一直等
2. 往 FIFO 写一个字节

**建议的 main 流程**：
1. 初始化 UART（复位 → 设 8N1 → 设波特率 → 使能收发）
2. 打印一段 banner
3. 顺便打印一下 `XPAR_PS7_CORTEXA9_0_CPU_CLK_FREQ_HZ`，验证你的板子 CPU 真的是 666.67 MHz
4. 死循环打印心跳

**写完**：`Project → Build All`，产出 `arm_hello_app/Debug/arm_hello_app.elf`

## 1.4 插板、下载、看输出

**你做：**
1. USB-C 线接 PC ↔ 板子 **J2 调试口**（丝印 `HUB / JTAG / UART`）

# 阶段 2 · RTL 侧（仿真先行）

**目标**：先让仿真跑通，再上板。

## 2.1 写你的第一个 RTL

**你要建**：`rtl/top/blink_top.sv`

**规格：**

| 项 | 要求 |
|---|---|
| 端口 | `clk50M`（输入）、`reset_n`（输入）、`led[7:0]`（输出） |
| 参数 | `CNT_WIDTH`，默认 **25** ← **必须是参数，不能写死** |
| 逻辑 | 一个 `CNT_WIDTH` 位计数器，同步/异步低有效复位 |
| 行为 | 计数器走满（全 1）时归零，并翻转一个 `heartbeat` 寄存器 |
| 输出 | 8 个 LED 一起跟随 `heartbeat` |

**为什么 `CNT_WIDTH` 必须是参数**：
- 上板用 25 → `2^25 / 50MHz ≈ 0.67s` 翻转一次
- 仿真用 3 → `8 拍` 就翻转，几十纳秒测完

**写死的话你就只能靠肉眼盯 2500 万拍，等于没法仿真。**

## 2.2 写对应的约束

**你要建**：`constrs/blink.xdc`

**规格：**
- `create_clock` 20 ns，绑到 `clk50M`
- `clk50M` → **L5**，`LVCMOS33`
- `reset_n` → **R4**，`LVCMOS33`
- `led[0]` ~ `led[7]` → 8 个引脚

**引脚号去哪查**：`constrs/acz7015/pinmap.csv` 或 `constrs/acz7015/acz7015.xdc` 的第 3 节。

> **`constrs/<工程名>.xdc` 是工程约束，只放你要用的。**
> `constrs/acz7015/acz7015.xdc` 是板级全量参考，**不要直接挂到工程上** ——
> 里面有你用不到的端口，会全部报错。

## 2.3 写测试平台

**你要建**：`sim/tb/tb_blink_top.sv`

**规格：**
- 实例化 DUT，**把 `CNT_WIDTH` 覆盖成 3**
- 生成 50 MHz 时钟（半周期 10 ns）
- 自检式：打印 `[PASS]` / `[FAIL]`，最后汇总，有失败就 `$fatal`
- 要检查的点：
  1. 复位期间 LED 全灭、计数器清零
  2. 释放复位后走满一圈 → LED 全亮、计数器归零
  3. 再走一圈 → 翻回来
  4. 走一半时复位 → 立即全部拉回初始状态
- 加一个仿真超时保险丝（`#100_000` 强制 `$finish`）

**跑：**
```bash
./scripts/build.sh sim -n blink -b tb_blink_top
```

**检查点**：所有 `[PASS]`，最后 `结果: 全部通过`。

## 2.4 上板

```bash
./scripts/build.sh pl -n blink -t blink_top
```

**检查点**：`build/out/.../blink_top.bit`

```
Xilinx → Program FPGA    ← 选这个 bit
```

**检查点**：8 个 LED 一起闪，约 0.75 Hz（1.3 秒一个完整周期）。

> LED 不动怎么办：先用 ILA 抓 `cnt`，看计数器有没有在动。
> 不动 → 时钟没进来（查 L5 约束）；在动但 LED 不动 → 输出逻辑问题。

# 阶段 3 · PL + PS 合体

**目标**：ARM 通过 AXI 控制 PL 的东西。

```bash
./scripts/build.sh zynq -n zynq_axi -a
```

`-a` 会额外生成：
```
/processing_system7_0
/axi_interconnect_0
/rst_ps7_50M
/axi_gpio_led       ← 8bit GPIO，接到板上 LED
```

**你要写的 C**：用 `XGpio` 驱动操作它。
- 查 `xparameters.h` 里那个 AXI GPIO 的**设备 ID 宏名**（由 BD 实例名决定）
- 初始化、设方向为输出、循环写 0xFF / 0x00

**检查点**：串口在打印的同时，LED 跟着亮灭 ——
**这就打通了「ARM 控制 PL」这条链。**

# 附录 B · 改约束的正确姿势

**用文本编辑器改，不要在 Vivado GUI 里改引脚。**

原因：GUI 保存约束时会**重写整个文件**，把注释和分节全冲掉。

```bash
grep -n "led\[" constrs/blink.xdc        # 定位
vim constrs/blink.xdc                     # 改
./scripts/build.sh pl -n blink -t blink_top   # 重新构建看报错
```

GUI 的正确用法是**看**：
```
Window → Package            看芯片引脚分布、哪些脚空着
Window → I/O Planning       看端口分配情况
report_io -file io.rpt      导出完整端口↔引脚表
```

要用更多外设 → 从 `constrs/acz7015/acz7015.xdc` 复制对应段落过来。
