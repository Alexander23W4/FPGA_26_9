~~~text
PL_REG_BASEADDR = 0x44000000
0x00 MODE

0x30 DBG0
~~~

~~~text

  -> AXI VDMA MM2S，64位
  -> top1
~~~

## Host GUI 使用说明

推荐在 Git Bash 仓库根目录运行 `bash ./network/launch_gui.sh`。脚本会启动或复用本机
mock PS 服务：控制连接在 `127.0.0.1:5000`，图像接收在 `127.0.0.1:5001`；GUI 页面在
`http://127.0.0.1:8765/`。运行后可点击 **“选择本地图像”** 打开文件选择器。退出时在
启动脚本的终端按 `Ctrl+C`。一键脚本不带 `--simulate` 参数，因此 GUI 内置模拟器初始为
关闭状态，状态和掩膜由 mock PS 提供。

### 图像选择、显示与上传

- 支持 PNG、JPG/JPEG、BMP、TIF/TIFF 和 BIN。普通图片会转为灰度并双线性缩放为
  256 x 256；BIN 必须已经是 256 x 256 的 8-bit 灰度裸数据，恰好 65536 字节。
- **“选择本地图像”**将浏览器选中的文件发送到本机 GUI 服务器，更新 GUI 当前图像和预览，
  并清除已有掩膜。选择本身不会启动分析，也不会把图片自动发给 mock 或 FPGA。
- **阈值模式开关**用于切换界面上的“自动/手动”选项。GUI 内置模拟模式开启时开关禁用并
  灰显；关闭后开关可用，滑块圆点变蓝。选择“手动”后，现有分割阈值数值滑块可调并向控制端
  发送阈值；选择“自动”时数值滑块禁用。当前 RTL/控制协议没有由此开关驱动自动/手动模式的
  后端接口，所以该开关只控制 GUI 状态和阈值滑块可用性，不代表实际切换 FPGA 阈值模式。
- **“传输给FPGA”**目前只是界面按钮，没有绑定点击处理函数，不会发起图像或控制数据传输。
- **“上传当前图像”**把 GUI 当前图像以图像包通过 TCP 发往 `--board-ip` 的 image port
  （默认 5001）。用一键脚本时目的地是本机 `127.0.0.1:5001` 的 mock PS，而非板卡；
  mock 只把图像保存在进程内存，不写磁盘，也不写入 DDR。对于真实板卡，实际存储/处理行为
  取决于板卡端运行的服务程序。
- 图片上传后，mock 按图像尺寸生成椭圆掩膜：中心在图像中心，水平半径为宽度的 22%，
  垂直半径为高度的 30%。判断公式为
  `((x - width/2)/(width*0.22))^2 + ((y - height/2)/(height*0.30))^2 <= 1`。
  满足公式的位置为前景 1，其余为背景 0。这是固定形状的演示数据，不读取像素内容，也不随
  阈值滑块改变；对 CAMUS 图像的结果不是实际分割。
- 四种下拉显示模式只是 GUI 渲染方式，不会启动或切换 PL 算法。显示前会根据窗位/窗宽
  映射灰度范围（范围外截为黑/白；范围内线性映射到 0–255）。

| 显示模式 | GUI 显示内容 |
| --- | --- |
| 原图 | 经窗位/窗宽映射后的灰度图。 |
| 增强 | 先做窗位/窗宽映射，再做 Gamma 变换 `255 * (gray/255)^0.75`；使中间灰度偏亮，黑白端点不变。 |
| 掩膜 | 只显示二值掩膜，背景黑色、前景白色。未收到掩膜时显示全黑。 |
| 叠加 | 在窗位/窗宽处理后的灰度底图上叠加掩膜：前景红色，边界青色；透明度由叠加透明度滑块控制。 |

**窗位**移动映射灰度范围的中心：调高后相同像素通常显示更暗，调低后通常显示更亮。
**窗宽**调整映射范围：变窄通常提高对比度、但更多像素会被截成纯黑或纯白；变宽通常降低
对比度、保留更多灰度层次。窗位、窗宽和显示模式只影响浏览器画面，不改写上传的原始像素，
也不会重新计算掩膜。

### 控件和状态栏

| 控件/字段 | 含义 |
| --- | --- |
| 切换模拟模式 | 开关 GUI 进程内的 `WebSimulator`。开启后它周期性生成一套独立的模拟掩膜和状态（其掩膜是动态的双椭圆形状），关闭后停止生成。它不会启动/关闭 mock PS，也不是切换真实 FPGA 连接的开关。开启时 GUI 内置模拟器与 mock PS 可能同时推送状态/掩膜，不宜将画面当作单一来源的结果。 |
| 自动/手动阈值开关 | 模拟开启时禁用；模拟关闭时可切换。手动模式下阈值滑块启用并发送阈值值；自动模式或模拟模式下阈值滑块禁用。开关目前只影响 UI，没有对应的后端模式命令，因此不能据此断言 FPGA 已切到自动/手动模式。 |
| 阈值更新 | 当前仅为界面按钮，没有绑定点击处理函数，不会发送阈值或触发其他操作。 |
| 请求 FPGA 状态 | 若 GUI 控制连接存在，发送 `CMD_REQUEST_STATUS`（命令码 `0x04`，无额外数据）请求当前状态；不会上传图片、启动分析或触发分割。没有控制连接时无设备可请求。mock PS 自己也每 200 ms 定期发送状态，因此点按钮主要是主动请求一次，并不表示 FPGA 刚刚处理了新图。 |
| 传输给FPGA | 当前仅为 UI 按钮，无点击后端行为。真正向板卡发送图像仍需“上传当前图像”并连接真实板卡服务。 |
| 选择本地图像 | 通过浏览器文件选择器载入和预览图像；不会自动上传。 |
| 上传当前图像 | 发送当前图像到 image port。若控制连接存在，随后还会发送当前阈值、PL 模式和 `START_ANALYZE` 命令。当前 mock 收到这些控制命令后，只更新/回报模拟状态，掩膜仍由上述固定椭圆公式生成。 |
| frame | 服务端报告的帧编号；上传时 GUI 递增分配。是编号，不是帧率或处理进度。 |
| mode | 状态包报告的服务端/PL 模式，并用 `原图/增强/掩膜/叠加` 名称显示。不是上方浏览器显示模式下拉框；浏览器下拉框只改变本地渲染。 |
| threshold | 服务端报告的阈值。mock 会保存并回报滑块传来的阈值，但不使用它生成椭圆掩膜。 |
| area_pixels | 状态包中的区域像素数。当前 mock 实际统计上传图像中非零像素的数量，并非生成的椭圆掩膜面积。 |
| area_mm2 | 状态包中的面积换算值。mock 按固定像素间距 `0.6605156214 mm/像素` 将 `area_pixels` 换算为平方毫米；由于面积像素统计不是掩膜面积，这也只是模拟值。 |
| inference_ms | 状态包报告的处理时间（毫秒）。mock 固定报告 18000 微秒，即约 18 ms，不是 FPGA 实测延迟。 |
| network | GUI 到控制服务的 TCP 连接状态。使用一键脚本时表示连接本机 mock PS，不代表已经连接 FPGA。 |
| simulate | GUI 内置 `WebSimulator` 的开关状态；与是否连接 mock PS 或 FPGA 是不同的概念。 |

以上 mock 的掩膜、面积、阈值和耗时适用于演示 GUI/通信流程，不能作为图像分析结果或硬件性能数据。
